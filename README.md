# Neutrino
Neutrino is a cross platfrom GUI framework which is still in the works

Neutrino/ folder contains the initial implementation
Neutrino_Stage2/ folder contains the latest, use this

NOTE:    
Still buggy on Windows (not crash related but appearance related)    
CPU usage very high on Linux    
Mac OS is untested    
Does not use Cairo    
Uses X11 or wayland on Linux   
Uses Basic Windowing on Windows
